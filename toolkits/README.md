# Toolkits

|---|---|---|
| `passport/` | `prep_refs.py`, `gen.py`, `build_site.py`, the site template and the skill | `person-visual-passport` |

Run the commands from this folder. `.gitignore` keeps real person folders (`people/<slug>/`),
`work`, `data/`, style corpora and productions out of git. Keep them in your private copy.
