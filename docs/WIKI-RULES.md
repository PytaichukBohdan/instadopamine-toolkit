# Creator DNA wiki: maintenance rules

This is the compiled evidence layer, following the LLM-wiki format (https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f). Start at the creator's index.md and coverage.md. Raw sources live in private, separately versioned corpus runs; never publish them by copying the corpus directory.

Every substantive topic claim needs a source-page link and, where applicable, an asset index or frame timestamp. Distinguish observed visuals, automatic transcript, public creator statement, guest statement, and interpretation. A source-page model output is not a verified fact merely because it is structured.

Never use face recognition to identify or link individuals across media. Names and public handles require textual attribution. Do not infer private/sensitive attributes, friendship, family relationships, garment brands, object ownership, or daily habits from appearance or coappearance. Do not create passports for incidental minors. Guest topics and claims are not the creator's personal beliefs.

Preserve coverage totals, selection bias, failed retrievals and model/ASR limitations. Never convert archive pagination exhaustion into whole-account completeness. Images have indices; only video frames have time offsets. Persistent graphic regions must not be described as separate temporal cards without evidence.

On ingest: preserve raw evidence and hashes; write/update source notes; update relevant entity/topic pages and crosslinks; record competing interpretations and corrections in questions.md; update index.md; append a UTC entry to log.md; run the wiki link checker. Review generated source notes for errors before promoting claims into the central passport.

Publish only explicitly selected, hash-validated reference images. Never add full raw transcripts, unselected media, video files, exact private locations or credentials to a site. A person's wiki is published behind a login unless that person's public material is explicitly cleared for public release.
